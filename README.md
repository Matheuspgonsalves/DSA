# DSA

Personal study of data structures and algorithms, in TypeScript, loosely following the chronology of PUC Minas' AEDS2 course (skipping anything Java-specific).

## Contents

- [`DataStructures`](./DataStructures) — data structures implemented from scratch (Array, Stack, Queue, Linked List, and more to come)
- [`Algorithms`](./Algorithms) — algorithmic techniques by category (Sorting, Search, Recursion, Divide and Conquer, Tree & Graph Traversal, Dynamic Programming, Backtracking, Greedy Algorithms)

Each topic/algorithm has its own independent folder with `src/`, `tests/`, and its own config:

```bash
cd <topic-folder>
npm install
npm test
```
