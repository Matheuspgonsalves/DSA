# Dynamic Programming

A technique for problems that can be broken into **overlapping** subproblems (unlike Divide and Conquer, where subproblems are independent) — you solve each distinct subproblem once, cache the result, and reuse it instead of recomputing it.

Covers both the top-down approach (recursion + memoization) and the bottom-up approach (iterative tabulation), typically starting from Fibonacci (memoized) before moving into classics like the Knapsack problem, Longest Common Subsequence, Coin Change, and Longest Increasing Subsequence.

Each algorithm/exercise gets its own subfolder, following the same pattern used under `Ordenacao/`: `PROBLEM.md`, `src/`, `tests/`, and its own config.
