# Search

Algorithms for finding a target value (or answering a search-shaped question) within a data structure, beyond straightforward array scanning.

This category covers variations and extensions of the search techniques already practiced elsewhere (e.g. plain binary search) — things like searching in a rotated sorted array, searching in an infinite/unbounded array, exponential search, interpolation search, or ternary search over a unimodal function.

Each algorithm/exercise gets its own subfolder, following the same pattern used under `Ordenacao/`: `PROBLEM.md`, `src/`, `tests/`, and its own config.
