# Tree & Graph Traversal

Systematic ways to visit every node of a tree or graph — the foundation for almost everything else you do with these structures (search, shortest paths, connectivity, ordering).

Covers: tree traversals (pre-order, in-order, post-order, level-order/BFS), depth-first search (DFS) and breadth-first search (BFS) on graphs, connected components, cycle detection, and topological sort.

Each algorithm/exercise gets its own subfolder, following the same pattern used under `Ordenacao/`: `PROBLEM.md`, `src/`, `tests/`, and its own config.
