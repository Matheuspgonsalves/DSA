# Greedy Algorithms

A technique where you make the locally optimal choice at each step, hoping (and, for the right problems, proving) that this leads to a globally optimal solution — without backtracking or reconsidering earlier choices.

Classic problems: activity/interval selection, fractional knapsack, coin change (works greedily only for certain coin systems), Huffman coding, Dijkstra's shortest path (also a graph traversal algorithm).

Each algorithm/exercise gets its own subfolder, following the same pattern used under `Ordenacao/`: `PROBLEM.md`, `src/`, `tests/`, and its own config.
