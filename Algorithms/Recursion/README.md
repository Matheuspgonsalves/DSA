# Recursion

The foundation for thinking in terms of "a problem defined in terms of a smaller version of itself."

This category is about building the base skill: identifying the base case(s) that stop the recursion, and the recursive case that reduces the problem toward that base case. Classic warm-up problems: factorial, Fibonacci (naive, exponential version — dynamic programming will revisit it with memoization), sum of digits, power/exponentiation, reversing a string recursively, Tower of Hanoi.

Recursion itself isn't a data structure or a single algorithm — it's a technique that later categories (Divide and Conquer, Tree/Graph Traversal, Backtracking, some Dynamic Programming solutions) all build on top of.

Each algorithm/exercise gets its own subfolder, following the same pattern used under `Ordenacao/`: `PROBLEM.md`, `src/`, `tests/`, and its own config.
