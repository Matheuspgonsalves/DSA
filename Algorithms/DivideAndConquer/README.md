# Divide and Conquer

A specific recursive strategy: split a problem into independent subproblems, solve each one recursively, then combine their results into the solution for the original problem.

Merge Sort and Quick Sort (already under `Ordenacao/`) are the textbook examples of this technique, so this category is for divide-and-conquer problems that go beyond sorting: finding the maximum subarray sum, the closest pair of points, fast exponentiation, majority element, Karatsuba multiplication.

Each algorithm/exercise gets its own subfolder, following the same pattern used under `Ordenacao/`: `PROBLEM.md`, `src/`, `tests/`, and its own config.
