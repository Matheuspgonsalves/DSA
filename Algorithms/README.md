# Algorithms

Personal implementations, in TypeScript, of the algorithmic techniques studied outside of work (loosely following the chronology of PUC Minas' AEDS2 course, skipping anything Java-specific).

Each subfolder is a category of algorithms, and inside it every algorithm has its own independent practice environment (`PROBLEM.md`, `src/`, `tests/`).

## Categories

- [`Sorting`](./Sorting) — sorting algorithms (Bubble, Insertion, Selection, Merge, Quick, Heap, Counting, Radix Sort)
- [`Search`](./Search) — search algorithms beyond plain array scanning
- [`Recursion`](./Recursion) — recursive thinking fundamentals
- [`DivideAndConquer`](./DivideAndConquer) — divide and conquer, beyond sorting
- [`TreeAndGraphTraversal`](./TreeAndGraphTraversal) — tree & graph traversal (BFS/DFS, topological sort, etc.)
- [`DynamicProgramming`](./DynamicProgramming) — dynamic programming (memoization & tabulation)
- [`Backtracking`](./Backtracking) — exhaustive search with pruning
- [`GreedyAlgorithms`](./GreedyAlgorithms) — greedy algorithms

More categories can be added here as the coursework progresses.
