# Backtracking

A technique for exploring all (or all valid) possibilities by building a solution incrementally, and abandoning ("backtracking" out of) a partial solution as soon as it can't possibly lead to a valid one.

Classic problems: N-Queens, generating all permutations or subsets of a set, Sudoku solver, word search in a grid, combination sum.

Each algorithm/exercise gets its own subfolder, following the same pattern used under `Ordenacao/`: `PROBLEM.md`, `src/`, `tests/`, and its own config.
