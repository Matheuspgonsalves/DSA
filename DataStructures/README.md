# Data Structures

Personal implementations, in TypeScript, of the data structures built from scratch while studying (loosely following the chronology of PUC Minas' AEDS2 course).

Each topic has its own independent folder, following the same pattern used under [`Algorithms`](../Algorithms): `src/`, `tests/`, and its own config.

## Topics

| Topic | Folder | Status |
|---|---|---|
| Dynamic Array | [`Array`](./Array) | ✅ Implemented |
| Stack | [`Stack`](./Stack) | ✅ Implemented |
| Queue | [`Queue`](./Queue) | ✅ Implemented |
| Linked List | [`LinkedList`](./LinkedList) | ✅ Implemented |
| Tree | [`Tree`](./Tree) | ⬜ Not implemented yet |
| Heap | [`Heap`](./Heap) | ⬜ Not implemented yet |
| Hash Table | [`HashTable`](./HashTable) | ⬜ Not implemented yet |
| Graph | [`Graph`](./Graph) | ⬜ Not implemented yet |

## Running a topic's tests

```bash
cd <topic-folder>
npm install
npm test
```
